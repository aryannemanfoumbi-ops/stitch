# stitch
Application mobile GlamAtHome-projet etude

**Öğrenci:** ester Ariane Manfoumbi
**Öğrenci Numarası:** 24010501133

## Projenin Amacı ve Kısa Açıklaması

GlamAtHome, kullanıcıları evde güzellik hizmeti sunan profesyoneller ile buluşturan bir mobil uygulamadır. Kullanıcılar sunulan hizmetleri görüntüleyebilir, randevu oluşturabilir ve hizmet sağlayıcılarla iletişim kurabilir.

## Kullanılan Teknolojiler / Kütüphaneler

* Node.js
* JavaScript
* HTML
* CSS
* Python (otomasyon scriptleri)
* PowerShell
* npm

## Proje Klasör Yapısı

* **images/** : Uygulamada kullanılan görseller
* **stitch/** : Uygulamanın ana bileşenleri
* **uploads/** : Kullanıcı tarafından yüklenen dosyalar
* **velvet_rose/** : Kullanıcı arayüzü dosyaları
* **server.js** : Sunucu dosyası
* **app.js** : Uygulama yapılandırması
* **build.py**, **clean.py**, **fix_*.py** : Python otomasyon ve bakım scriptleri
* **package.json** : Proje bağımlılıkları ve npm ayarları

## Kurulum ve Kullanım

1. Projeyi klonlayın:

   ```bash
   git clone https://github.com/aryannemanfoumbi-ops/stitch
   ```

2. Gerekli paketleri yükleyin:

   ```bash
   npm install
   ```

3. Uygulamayı çalıştırın:

   ```bash
   node server.js
   ```
